# Public release preparation

The base plugin is published in the Plugin Hub. The golden tench celebration update is a new release candidate awaiting its own Hub review.

## Before publishing

- Public GitHub owner, author and BSD-2-Clause copyright name confirmed: Moldead.
- Review the remaining live cases in VALIDATION.md. Record what was actually tested; do not claim automated event tests prove live server behavior.
- Five-second hourly display confirmed in game by Moldead on 2026-09-19. Accessible live cases confirmed; extreme cases remain documented limitations.
- Recheck the estimated pearl formula against current game documentation before advertising it as exact.
- Keep the removed configurable overlay visibility feature out of this release.
- Review the final source and the independent review notes, including any unresolved findings.

## Publish and submit

1. Use the existing public repository: https://github.com/Moldead/aerial-fishing-tracker.
2. Publish only the reviewed source distribution generated by `scripts/Prepare-Release.ps1`, or inspect every staged file in this workspace. Never upload the entire working folder: it contains local tools, diagnostics and MLflow data.
3. Run `bash ./gradlew clean test build --no-daemon` with JDK 17 in the clean checkout. Production bytecode targets Java 11. JUnit, Mockito, the launcher and preview are test-only.
4. Commit and push the reviewed revision. Record its full 40-character Git commit hash.
5. Fork `https://github.com/runelite/plugin-hub` and update `plugins/aerial-fishing-tracker` on a new branch:

   ```properties
   repository=https://github.com/Moldead/aerial-fishing-tracker.git
   commit=FULL_REVIEWED_COMMIT_HASH
   ```

6. Open one pull request describing the tracker and its validation. Address Hub CI and reviewer feedback in that PR, updating the manifest hash whenever source changes.
7. Wait for maintainer review and publication. Approval is not guaranteed; do not advertise the plugin as approved before it is accepted.

Suggested PR description: "Adds Aerial Fishing Tracker: per-character aerial fishing counts, session rates, pearl intervals, historical additions and cumulative golden-tench odds. The overlay is limited to Molch Island. Statistics use RuneLite configuration; the production plugin has no network calls or gameplay automation. Includes automated tests and documented live-validation boundaries."

The optional Plugin Hub icon must be at most 48x72 pixels. No icon is required for initial submission.

## Scope and rules

This plugin displays statistics from game events; it does not click, automate fishing, modify menu actions, or send data to a third-party service. Saved data uses RuneLite configuration, so RuneLite's own synchronization behavior may apply. The plugin has no separate telemetry.

Source review and tests are preparation, not a certification of compliance. RuneLite maintainers decide acceptance under their current rules. Follow the official instructions at submission time:

- https://github.com/runelite/plugin-hub
- https://github.com/runelite/runelite/wiki/Rejected-or-Rolled-Back-Features

Future updates require a new Plugin Hub manifest commit and review. Maintain the public repository and respond to issue reports.
